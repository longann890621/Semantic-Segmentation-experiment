# DeepLabV3語意分割實驗：前處理對模型預測穩定性影響
這是一個使用 PyTorch 和 torchvision 中的 DeepLabV3-ResNet101 模型進行語意分割的小型實驗，觀察不同影像前處理（模糊、亮度/對比度調整）對模型預測結果的影響。

## 📌 專案目的
- 實作語意分割任務，理解語意分割輸出結構與視覺化技巧。
- 比較影像前處理對語意分割結果的穩定性與影響。
- 建立一個可執行的 VS Code 專案，作為入職前技能實作的一部分。

##  範例輸出結果

模型會依序顯示三張圖片，每張圖疊加了語意分割的遮罩：

| 原圖 | 模糊處理後 | 亮度/對比調整後 |
|------|------------|-----------------|
| ✅ 可辨識人物與背景 | 🔍 模糊邊緣但仍可分割 | ⚠ 光線強烈處可能誤判 |

> 使用者可視覺化並觀察 DeepLabV3 模型在各種條件下的行為與穩定性。

## 使用技術
- Python 3.10
- PyTorch
- torchvision（含預訓練 DeepLabV3 模型）
- OpenCV（影像前處理與遮罩混合）
- Matplotlib（圖像顯示）
- NumPy
